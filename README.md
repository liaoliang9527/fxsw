# 废墟守望 · 微信小程序试玩版

根据《割草游戏产品需求文档》制作的原生微信小程序项目。界面使用 WXML/WXSS，战斗使用小程序 Canvas 2D，没有使用 `web-view`，无需网络即可运行。

## 导入运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本文件夹 `废墟守望微信小程序`。
3. 体验时可使用测试号；若要真机调试或发布，请在开发者工具中换成你自己的小程序 AppID。
4. 导入后直接点击“编译”。项目会以横屏运行。

项目配置中的默认 AppID 为 `touristappid`，只用于本地体验。

## 操作方式

- 在大厅选择角色，点击“开始游戏”。
- 按住左下角虚拟摇杆移动，角色会自动攻击最近的敌人。
- 升级时从三张卡牌中选择武器或被动能力，可使用一次刷新。
- 右上角按钮可暂停、继续或结束本局。
- 5 分钟出现精英，10 分钟出现首领，15 分钟进入最终首领战。

## 无尽轮回

- 击败最终首领深渊监视者后，可选择“踏入无尽轮回”继续挑战，或领取胜利结算。
- 无尽以 2.5 分钟为一层：开局群潮、中段双精英、尽头无尽首领（铁墓守卫与深渊监视者交替），首领血量逐层提升。
- 敌人生命与伤害逐层增强，无上限；击破无尽首领获得宝箱、生命回复与金币。
- 武器被动全满级后，升级卡改为“无尽淬炼”：所有伤害 +6%、最大生命 +4，可持续叠加。
- 结算记录无尽层数与无尽存活时长，大厅展示无尽最佳层数，无尽快照支持断局续玩。

## 已实现内容

- 3 名角色、14 种武器、11 种被动能力、6 类普通敌人
- 暴击、汲血、荆棘、不死鸟、幸运等质变型被动
- 六套构筑流派标签、跨武器联动、升级卡构筑保底、单卡锁定与成型武器优先进化
- 祭坛守点、补给残骸、四类环境异变，以及拥有场地变化和狂暴阶段的三阶段 Boss
- 自动攻击、经验升级、金币、宝箱、精英与首领
- 独立 Boss 系统：铁墓守卫、深渊监视者、范围预警、召唤与环形弹幕
- 3 次定时怪物群潮：边缘成批入场、剩余数量提示、逐波增强和清场奖励
- 回旋刃采用弧线去程与追踪回程，去程和回程可分别命中
- 局内构筑、暂停、结算、角色解锁、通用天赋
- 无尽轮回：通关后挑战逐层增强的敌潮，无尽淬炼持续成长
- 重复游玩：五档难度逐步解锁、每日契约、成就奖励与武器/词缀/首领图鉴
- 角色专属主动技能、敌人词缀、局内事件与补给
- 本地存档与断局续玩
- 低画质模式与触感反馈开关
- 横屏适配和安全区域处理

## 目录

- `pages/index/`：大厅、HUD、弹窗和 Canvas 战斗逻辑
- `utils/config.js`：角色、武器、被动、敌人与关卡参数
- `assets/`：压缩后的角色立绘、武器、被动和掉落物图片
- `project.config.json`：微信开发者工具项目配置

## 当前版本说明

这是可玩的单机关卡原型。排行榜、微信登录、云存档、支付、广告和正式音频资源尚未接入；它们需要对应的小程序账号能力、后台服务或授权素材。
