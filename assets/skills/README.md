# 武器技能序列帧

本次新增的 11 种技能特效使用透明 PNG 横向精灵条，每张 6 帧，单帧 128×128。已有火焰瓶素材保留 18 帧，其余已有技能维持原帧数。`utils/config.js` 中 `effectFrames`、`effectColumns` 和 `effectFps` 控制帧数、列数和播放速度。

| --- | --- | --- |
| 回旋刃 | `blade-skill.png` | 飞刃旋转 |
| 火焰瓶 | `flask-skill.png` | 火焰爆燃与余烬 |
| 穿风箭 | `arrow-skill.png` | 箭矢飞行 |
| 雷击 | `lightning-skill.png` | 落雷与电弧 |
| 守护环 | `ring-skill.png` | 环刃旋转 |

| 暗影鸦 | `raven-skill.png` | 幽鸦振翅飞行 |
| 守卫图腾 | `totem-skill.png` | 图腾显形与符文点亮 |
| 灵魂飞书 | `tome-skill.png` | 魔典开合与翻页 |
